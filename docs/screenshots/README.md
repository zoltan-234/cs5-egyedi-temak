# Képernyőképek az útmutatóhoz

Fájlnév: `<AZONOSÍTÓ>.png` (vagy .jpg/.webp) ebbe a mappába. Ezután: `python3 tools/build-guide.py` (a hiányzó képek helyén helyőrző marad; `--strict` hibával leáll).

| Azonosító | Mit kell lefotózni |
|---|---|
| `GH-01` | A repó Releases oldala (…/releases/latest), a lenti 'Assets' lista látszódjon: a .xpi és a -chromium.zip fájl. Jelöld be (pl. piros keret) a két fájlt. |
| `GH-02` | A Fájlkezelőben a kicsomagolt mappa tartalma, jól látható a manifest.json fájl és a content, popup, themes mappák. A címsorban látszódjon a mappa neve. |
| `FF-01` | A Firefoxban a letöltött .xpi megnyitása után felugró ablak 'Hozzáadja a(z) CS5 Témák kiegészítőt?' – a Hozzáadás gombbal együtt. |
| `FF-02` | about:addons oldal, a Bővítmények között az CS5 Témák látszódjon, bekapcsolt állapotban. |
| `FF-03` | A CooSpace oldalon a bővítmény ikonjára kattintva megnyíló popup, a sárga 'Engedélyezés' dobozzal együtt (még az engedélyezés ELŐTT). |
| `FF-05` | A CooSpace főoldala (Áttekintés) egy látványos témával és stílussal – szebb legyen, mint az eredeti. |
| `FF-06` | about:addons, az CS5 Témák melletti három pontos (…) menü megnyitva, az 'Eltávolítás' sor látszódjon. |
| `CH-01` | chrome://extensions oldal, jobb felül a 'Fejlesztői mód' kapcsoló BEkapcsolva, jelöld be. |
| `CH-02` | Ugyanez az oldal a fejlesztői mód bekapcsolása után: bal felül a 'Kicsomagolt bővítmény betöltése' gomb, jelöld be. |
| `CH-03` | A mappaválasztó ablak, kijelölve a kicsomagolt mappa (amiben a manifest.json van). |
| `CH-04` | A bővítménykezelőben az CS5 Témák kártya, hibajelzés (piros) nélkül. |
| `CH-05` | A puzzle ikon menüje megnyitva, az CS5 Témák mellett a kitűző (tűzőcsap) ikon, jelöld be. |
| `CH-06` | chrome://extensions, az CS5 Témák kártyán az 'Eltávolítás' gomb, jelöld be. |
| `ED-01` | edge://extensions oldal; a bal oldali menüben a 'Fejlesztői mód' kapcsoló BEkapcsolva, jelöld be. |
| `ED-02` | Ugyanez az oldal fejlesztői móddal: a 'Kicsomagolt betöltése' gomb, jelöld be. |
| `ED-03` | A mappaválasztó ablak, kijelölve a kicsomagolt mappa. |
| `ED-04` | Az CS5 Témák kártya az edge://extensions oldalon, hibajelzés nélkül. |
| `ED-05` | A Bővítmények (puzzle) menü megnyitva, az CS5 Témák mellett a szem/kitűző ikon, jelöld be. |
| `ED-06` | edge://extensions, az CS5 Témák kártyán az 'Eltávolítás' gomb. |
| `BR-01` | brave://extensions oldal; a 'Fejlesztői mód' kapcsoló BEkapcsolva, jelöld be. |
| `BR-02` | Ugyanez az oldal fejlesztői móddal: a 'Kicsomagolt bővítmény betöltése' gomb, jelöld be. |
| `BR-03` | A mappaválasztó ablak, kijelölve a kicsomagolt mappa. |
| `BR-04` | Az CS5 Témák kártya a brave://extensions oldalon, hibajelzés nélkül. |
| `BR-05` | A Bővítmények (puzzle) menü megnyitva, az CS5 Témák mellett a kitűző ikon, jelöld be. |
| `BR-06` | brave://extensions, az CS5 Témák kártyán az 'Eltávolítás' gomb. |
| `US-01` | A bővítmény popupja nyitva a CooSpace oldalon, a 'Színek' rész teteje látszódjon (Világos, Többszínű csoportok). |
| `US-02` | Ugyanaz a popup legörgetve a 'Stílus' részhez: Klasszikus, Modern, Üveg, Szigetek, Brutalista. |
| `US-03` | A CooSpace Színterek oldala Modern stílussal és egy világos témával (pl. Világos modern vagy Pasztell). Személyes adat (név) legyen kitakarva, ha kell. |
| `US-04` | A CooSpace Áttekintés oldala Üveg stílussal és az Aurora témával. |
| `US-05` | A CooSpace Színterek oldala Brutalista stílussal és pl. a Rózsakert vagy Dracula témával. |
